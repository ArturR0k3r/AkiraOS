# Launch drafts

Draft copy for announcing AkiraOS. These are starting points to edit before posting —
not final. Ground rules, so a launch audience trusts us:

- **No unsourced numbers.** Don't quote performance figures that aren't published in
  [Performance](../resources/performance.md). Say "not yet benchmarked" if asked.
- **Be honest about status.** C is supported; Rust and MicroPython are experimental.
  Default builds are unsigned; signing is the `--release` flow.
- **Lead with the simulator** — the first line of every draft is the browser link, so a
  reader can try it in one click.
